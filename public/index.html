Comment ça marche

  1. 1

    Je prépare

    J'ajoute mes photos avec une légende, j'écris la lettre, je choisis un code à 6 chiffres et un indice.

  2. 2

    J'envoie

    Chaque surprise a son propre lien, et une carte QR à imprimer ou glisser dans un cadeau.

  3. 3

    Elle découvre

    Elle trouve le code, puis découvre le profil, les jours passés ensemble, la lettre et les souvenirs en Polaroid.

Sous le capot

Interface

HTML, CSS et JavaScript, sans framework. Pensée mobile d'abord, animations légères, émojis redessinés à l'encre.

Back-end Supabase

Authentification, base PostgreSQL protégée par des règles RLS, stockage privé des photos et une Edge Function qui vérifie le code côté serveur.

Sécurité

Photos servies par des liens temporaires signés, pause automatique après trop d'essais, en-têtes CSP stricts. La personne qui reçoit le lien n'a jamais accès à la base.

Gestion des comptes

Inscription sur code d'activation, espace propriétaire pour générer les codes, suivre les clients et nettoyer les photos inutilisées.
